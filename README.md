# CIRITS — site institutionnel

Site public du **Centre International de Recherches et d’Innovations en Travail Social (CIRITS)**, publié avec GitHub Pages.

## Architecture

- `/` — Accueil
- `/qui-sommes-nous/` — Identité institutionnelle
- `/cyril-malglaive/` — Profil de Cyril Malglaive
- `/recherches/` — Programme scientifique
- `/recherches/trajectoires-transformationnelles/` — Cadre CIRITS des trajectoires transformationnelles
- `/programmes/` — Programmes de recherche
- `/programmes/child-exit/` — CHILD-EXIT
- `/publications/` — Notes et publications CIRITS

## Principes éditoriaux

Le site distingue clairement :

1. les **programmes de recherche** ;
2. les **cadres conceptuels** ;
3. les **publications** et leurs identifiants pérennes.

Les formulations scientifiques doivent distinguer les hypothèses, les propositions conceptuelles et les résultats empiriquement établis.

Les personnes extérieures, chercheurs et partenaires ne sont présentés comme membres, associés ou partenaires qu’après accord explicite sur la formulation publique de leur lien avec le CIRITS.

## Maintenance

Lors de l’ajout ou de la modification d’une page publique :

- conserver une URL canonique ;
- maintenir le titre et la meta-description ;
- mettre à jour `sitemap.xml` si une nouvelle URL est créée ;
- vérifier la navigation mobile ;
- préserver un seul `h1` par page ;
- maintenir les données structurées JSON-LD lorsqu’elles existent ;
- vérifier les liens internes et les identifiants DOI.

Le sitemap est déclaré dans `robots.txt`.

## Publication

Le site est déployé automatiquement par GitHub Pages depuis la branche `main`.
